# 🤖 Resume Reviewer AI Agent

An AI-powered **Resume Reviewer Agent** built using **Streamlit**, **LangChain**, and **OpenAI API**.  
Upload your resume (PDF) and get instant, intelligent feedback with improvement suggestions from an AI model trained to evaluate resumes professionally.

---

## 🚀 Features
- 🧠 **AI-Powered Feedback** — Analyzes resume content for clarity, structure, and effectiveness.
- 📄 **PDF Upload Support** — Simply upload your resume to get started.
- 💬 **Detailed Suggestions** — Get actionable points to improve phrasing, formatting, and impact.
- ⚙️ **LangChain Integration** — Manages prompts and model logic seamlessly.
- 🎨 **Streamlit UI** — Clean, interactive web interface.

---

## 🧩 Tech Stack
- **Python 3.10+**
- **Streamlit** (for UI)
- **LangChain** (for LLM integration)
- **OpenAI API** (for text analysis)
